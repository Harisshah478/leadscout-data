# LeadScout Data — Website Copy

This document is a full copy audit of every user-facing piece of text on the LeadScout Data website (leadscout-data.vercel.app), current as of 2026-09-12. It's meant for an SEO/copywriting pass — everything below is organized by page and by the section it appears in, so it can be handed to a copywriter to rewrite without them needing to dig through the site's code. Text is quoted directly as it appears live; it is not narrative description of the page.

Not included: HTML/CSS/JavaScript, SVG icon artwork, and (on the Categories page) the 1,757 individual category names — see the note in that page's section for why.
